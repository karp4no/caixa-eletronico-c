# Simulador de Caixa Eletrônico em C
Atividade prática da disciplina de **Algoritmos e Pensamento Computacional** (Graduação EaD - Cruzeiro do Sul).

## 🚀 Funcionalidades
- Menu interativo utilizando laço de repetição (`do-while`).
- Estrutura de decisão múltipla (`switch-case`).
- Operações de **Consulta de Saldo**, **Depósito** e **Saque**.
- **Regra de Bônus:** Validação de segurança que impede saques superiores ao saldo base disponível.
